# Agent 设置与会话模型

交互参考 [Chatbox 的会话设置](https://github.com/chatboxai/chatbox/blob/0ac6385ae1ff5bf778777826da3c5edcd55b61b8/src/renderer/modals/SessionSettings.tsx)及其配置结构。独立实现 Flutter 界面、存储与请求逻辑，没有复制其源码。

## 设置页

顶部固定「生图 / Agent / 通用」三个页签。生图包括图片服务、密钥、默认图片模型、参考图数量及兼容选项；Agent 包括对话服务、协议、密钥、默认对话模型、看图能力、系统提示词与模型参数；通用包括语言、外观、代理与存储说明。

Agent 参数按模型 ID 保存。系统提示词默认保留旧版内容，允许完整替换、留空不发送或恢复内置提示词。不会在用户的自定义提示词后追加原内置提示词。生图工具的描述、参数校验及每轮只接受一个工具调用的应用逻辑继续独立生效。

## 对话内调整

输入区可切换 Agent 或图片模型，支持手动输入模型 ID、搜索或主动获取服务的模型列表。沿用已经配置的服务地址和密钥；切换模型不会自动更换供应商，也不证明模型具备工具调用或图片能力。

模型选择仅作用于当前会话，下一条提交开始使用。聊天历史及输入草稿保留；进行中的请求禁用切换。Agent 回复记录所用的模型 ID，旧消息没有该字段仍可读取。会话中的参数按模型分别保存，切回时恢复，重启及切换历史会话也能恢复。新对话继承设置页的默认值。

## 参数语义

- 上下文消息数量：0 发送全部；正数仅携带最近若干条消息，包括本次用户消息，必要时跳过开头孤立的 assistant 消息。本地历史不删除。这是消息条数限制，不是 Token 计数、模型窗口大小或自动摘要。
- 最大输出 Tokens：可选正整数。OpenAI 兼容协议发送 `max_completion_tokens`；Claude 发送 `max_tokens`，留空使用原有的 2048 默认值。服务必须支持所填参数及数值范围。
- Temperature / Top P：留空不发送。Temperature 的应用校验范围为 OpenAI 0–2、Claude 0–1；Top P 为 0–1。Claude 仅允许填写其中一种，避免同时传参被拒绝。部分模型不接受采样参数，应留空。
- 系统提示词：OpenAI 作为 system 消息发送；Claude 作为顶层 system 字段发送；留空时均省略。

模型上下文上限与输出上限最终由服务决定。应用不静默换模型、不自动重试收费请求，也不会用开发用的 GitHub 代理转发生图或对话请求。

## 验证

本机 HTTP 回环验证两种协议的模型 ID、自定义系统提示词、上下文裁剪、输出参数、空值省略与回复模型记录。存储测试验证旧配置迁移、按模型保存、会话恢复与新会话默认值；360px 窄屏测试验证页签、提示词跨页保存和切模型保留草稿。没有调用真实付费接口。
