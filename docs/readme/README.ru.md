# Imagyn

Лаконичное приложение для создания изображений с ИИ с двумя разделами: **Галерея** и **Agent**. Используйте собственный API-ключ и подключайтесь напрямую к совместимому сервису. Работы остаются на вашем устройстве. Приложение доступно для Android, Linux, Windows и macOS; интерфейс переведён на шесть официальных языков ООН.

> Статус: **в разработке.** См. [поддерживаемые возможности](#поддерживаемые-возможности): подключение совместимого адреса само по себе не гарантирует генерацию изображений. Это моё первое приложение такого рода — спасибо за терпение.

## Два раздела

| Раздел | Возможности |
| --- | --- |
| **Галерея** | Создание изображений по описанию, без образцов или с несколькими образцами. Они пронумерованы, поэтому можно попросить «персонажа с изображения 1 в одежде с изображения 2». |
| **Agent** | Создание и редактирование изображений в диалоге. Обсуждение и генерация имеют разные статусы; обычная беседа не запускает платную генерацию незаметно для пользователя. Каждое изменение сохраняется отдельной версией, а созданные изображения появляются и в галерее. Он также может последовательно вызывать инструменты: генерировать изображения, создавать презентацию, добавлять текст и таблицы по страницам, просматривать страницы в отдельной рабочей области и экспортировать редактируемый `.pptx`. |

Настройки вынесены на отдельную страницу с тремя вкладками: **Изображения / Agent / Общие**. В ходе диалога можно менять модель и настраивать для каждой модели системную инструкцию, количество сообщений в контексте и параметры ответа. История и черновик сохраняются. Есть режим уменьшения анимации.

## Особенности

- **Локальное хранение:** история хранится в SQLite в закрытой папке приложения. Работы сохраняются локальными файлами и не зависят от временных ссылок. API-ключи находятся в защищённом хранилище системы, а не в базе данных.
- **Agent работает шагами:** в рамках одного тура он может многократно вызывать инструменты (генерация изображений, сборка колоды, таблицы, вопросы). Ошибка инструмента возвращается модели как результат, чтобы она продолжила; тур завершается только при ошибке запроса к текстовой модели. Остановка сохраняет уже написанный текст как контекст следующего тура.
- **Презентации:** `create_deck` → `add_slide` → `add_table` → `finish_deck`, с предпросмотром по страницам в рабочей области. Экспорт — нативный OOXML `.pptx`; текстовые блоки, изображения и таблицы остаются редактируемыми в PowerPoint / WPS. Одна таблица на слайд, до 12 строк × 8 столбцов и 500 символов в ячейке.
- **Собственный сервис:** настройте базовые адреса, модели для изображений и диалогов, протокол (OpenAI Chat Completions / OpenAI Responses / Anthropic Messages) и при необходимости HTTP-прокси. Для диалогов и изображений можно использовать разные сервисы.
- **Понятные статусы задач:** различаются ошибка отправки, неизвестный результат, генерация и ошибка скачивания. Если после отправки истёк срок ожидания, платный запрос не повторяется автоматически: результат остаётся «неизвестным», чтобы вы могли его проверить.
- **Шесть языков:** 中文, English, Français, Español, Русский и العربية, включая интерфейс справа налево для арабского.
- **Android без root:** изображения сохраняются через системный API мультимедиа в общую папку `Pictures/Imagyn/` и видны в галерее. Несколько образцов можно выбрать через системный выбор файлов. Google Play Services не требуется.

## Поддерживаемые возможности

«Совместимость с OpenAI / Claude» означает формат запросов и **не гарантирует** генерацию изображений, количество образцов, прозрачность, разрешения или восстановление задач. Текущее состояние:

| API или возможность | Статус |
| --- | --- |
| OpenAI Images (`images/generations`, `images/edits`) | Реализовано: несколько образцов, результат в виде URL / Base64 |
| OpenAI Chat Completions + вызовы инструментов | Реализовано в режиме Agent (`/chat/completions`) |
| OpenAI Responses + вызовы инструментов | Реализовано в режиме Agent (`/responses`) |
| Anthropic Messages + вызовы инструментов | Реализовано в режиме Agent |
| Многошаговый цикл инструментов Agent (`generate_image`, `create_deck`, `add_slide`, `add_table`, `ask_user`, …) | Реализовано, до 32 шагов за тур; ошибки инструментов возвращаются модели как результаты |
| Экспорт презентации (`.pptx`, текстовые блоки / изображения / таблицы) | Нативный OOXML; редактируется в PowerPoint / WPS (открытие на реальном устройстве ещё не проверено) |
| WebFetch / `fetch_url` | Исполнитель и схема инструмента ещё в PR; не подключено к циклу |
| Результаты OpenAI Images через SSE | Реализовано; включается в параметрах совместимости API изображений |
| Встроенный инструмент Responses `image_generation` | Не реализован; Agent вызывает отдельный Images API через функцию приложения `generate_image` |
| Редактирование по маске, пакетные задачи, облачная синхронизация, локальный запуск моделей | Не реализовано; возможные дальнейшие расширения |

Список моделей не доказывает возможность генерации изображений, а проверка соединения не заменяет её тест. Платная проверка запускается только при явной отправке запроса в галерее. Подробнее: [docs/capabilities.md](../../docs/capabilities.md).

## Сборка

Требуется Flutter с Dart SDK ≥ 3.12.

Папки платформ генерируются и не хранятся в Git. Затем скрипт добавляет в них собственные нативные файлы проекта:

```bash
python3 scripts/scaffold_platforms.py     # Создаёт android/ linux/ windows/ macos/
flutter pub get
flutter run -d <device>
flutter build apk --release
```

В CI три процесса: `check` (анализ и тесты), `build` (тестовый Android APK) и `release` (пакеты для четырёх платформ, запуск по тегам `v*`).

Пакеты выпуска:

| Платформа | Пакеты | Инструменты |
| --- | --- | --- |
| Android | APK | Подписан ключом выпуска |
| Linux | `.deb` / `.rpm` / `.pkg.tar.zst` | `dpkg-deb` / `rpmbuild` / `bsdtar` |
| Windows | `.exe` / `.msi` (только x64) | Inno Setup / WiX |
| macOS | `.dmg` / `.pkg` | `hdiutil` / `pkgbuild` |

Пакеты для компьютеров **не подписаны**: Windows SmartScreen сообщает о «неизвестном издателе», а в macOS приложение нужно открывать через правый клик. Чтобы убрать эти предупреждения, нужны сертификат Authenticode и Apple Developer ID, которых у меня пока нет. **32-битной версии Windows нет**, поскольку Flutter не предоставляет такую целевую платформу. Пока прошу прощения у пользователей Windows 7 и других систем win32.

## Структура проекта

```text
lib/core/    Хранение, модели данных, адаптеры API, состояние приложения и запись .pptx
lib/ui/      Интерфейс Галерея / Agent, рабочая область колоды и настройки
lib/l10n/    Тексты и таблицы переводов на шесть языков
platform/    Нативные файлы проекта, добавляемые к результату flutter create
scripts/     Создание папок платформ и генерация переводов
docs/        Руководства по API и функциям
test/        Разбор протоколов, проверка настроек и переводов
```
