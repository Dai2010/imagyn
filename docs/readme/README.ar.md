# Imagyn

تطبيق بسيط لإنشاء الصور بالذكاء الاصطناعي، يضم قسمين: **المعرض** و**Agent**. استخدم مفتاح API الخاص بك واتصل مباشرة بخدمة متوافقة. تبقى أعمالك على جهازك. يتوفر التطبيق لأنظمة Android وLinux وWindows وmacOS، بواجهة تدعم اللغات الرسمية الست للأمم المتحدة.

> الحالة: **قيد التطوير.** راجع [الميزات المدعومة](#الميزات-المدعومة)؛ فالاتصال بعنوان متوافق لا يضمن توليد الصور. هذا أول تطبيق أعمل عليه من هذا النوع، فشكرًا على تفهمكم.

## قسمان

| القسم | الوظيفة |
| --- | --- |
| **المعرض** | أنشئ صورًا من وصف نصي، دون صور مرجعية أو باستخدام عدة صور. تُرقّم المراجع، ويمكنك طلب «الشخص الموجود في الصورة 1 بملابس الصورة 2». ويفتح زر الفيديو في شريط العنوان صفحة فيديو مستقلة تُنتج مقطعًا من 3 إلى 12 ثانية من جملة واحدة. |
| **Agent** | أنشئ الصور وعدّلها عبر المحادثة. تظهر للمناقشة والتوليد حالات منفصلة؛ ولا تبدأ المحادثة العادية توليدًا مدفوعًا دون علمك. يُحفظ كل تعديل كنسخة مستقلة، وتظهر الصور الناتجة أيضًا في المعرض. ويمكنه أيضًا استدعاء الأدوات تباعًا: توليد الصور، وإنشاء عرض تقديمي، وإضافة النصوص والجداول صفحة بصفحة، ومراجعة الصفحات في مساحة عمل مستقلة، ثم تصدير ملف `.pptx` قابل للتحرير. |

للإعدادات صفحة مستقلة بثلاث علامات تبويب: **الصور / Agent / عام**. يمكنك تبديل النموذج أثناء المحادثة وتخصيص تعليمات النظام وعدد رسائل السياق ومعلمات الإخراج لكل نموذج، مع الاحتفاظ بالسجل والمسودة. ويتوفر خيار لتقليل الحركة.

## الميزات

- **التخزين المحلي أولًا:** يُحفظ السجل في SQLite داخل مجلد التطبيق الخاص. تُحفظ الأعمال كملفات محلية ولا تعتمد على روابط مؤقتة. تُخزّن مفاتيح API في مخزن النظام الآمن، وليس في قاعدة البيانات.
- **الفيديو:** صفحة مستقلة تضم سبعة نماذج مدمجة — Seedance 1.0 Pro / Lite وSora 2 وVeo 3.1 وKling 2.5 وWan 2.5 وHailuo 02 — مع إمكانية كتابة معرّف آخر أو جلب القائمة من خدمة الفيديو. اختر النسبة والدقة والجودة والمدة (3–12 ثانية) والعلامة المائية والكاميرا الثابتة والبذرة؛ ويُمرَّر النمط ضمن الوصف. ويمكن أن تكون لخدمة الفيديو عناوينها ومفاتيحها الخاصة في الإعدادات؛ وتركها فارغة يعني استخدام خدمة الصور. تُستعلم المهمة كل 5 ثوانٍ، ثم يُحفظ المقطع محليًا ويمكن حفظه على الجهاز. ويستطيع Agent أيضًا استدعاء `generate_video` بالمعلمات نفسها، بما فيها النموذج.
- **يعمل Agent على خطوات:** يمكنه في الدور الواحد استدعاء الأدوات عدة مرات (توليد الصور، وتوليد الفيديو، وبناء العرض، والجداول، وسؤالك). تُعاد أخطاء الأدوات إلى النموذج كنتائج ليواصل؛ ولا ينتهي الدور إلا بفشل طلب نموذج النص. وعند الإيقاف يبقى النص المكتوب سياقًا للدور التالي.
- **العروض التقديمية:** `create_deck` → `add_slide` → `add_table` → `finish_deck`، مع معاينة صفحة بصفحة في مساحة العمل. التصدير بتنسيق OOXML أصلي `.pptx`؛ وتبقى مربعات النص والصور والجداول قابلة للتحرير في PowerPoint / WPS. جدول واحد لكل شريحة، حتى 12 صفًا × 8 أعمدة و500 حرف لكل خلية.
- **خدمتك الخاصة:** اضبط عناوين الاتصال الأساسية ونماذج الصور والمحادثة والبروتوكول (OpenAI Chat Completions / OpenAI Responses / Anthropic Messages)، مع وكيل HTTP اختياري. ويمكن استخدام خدمتين مختلفتين للمحادثة والصور.
- **حالات مهام واضحة:** يميّز التطبيق بين فشل الإرسال والنتيجة المجهولة والتوليد الجاري وفشل التنزيل. إذا انتهت مهلة الانتظار بعد الإرسال، فلن يُعاد الطلب المدفوع تلقائيًا؛ بل تبقى النتيجة «مجهولة» لتتحقق منها بنفسك.
- **ست لغات:** 中文 وEnglish وFrançais وEspañol وРусский والعربية، مع تخطيط من اليمين إلى اليسار للعربية.
- **Android دون root:** تُحفظ الصور عبر واجهة الوسائط في النظام داخل المجلد العام `Pictures/Imagyn/`، فتظهر في تطبيقات المعرض. يمكن اختيار عدة صور مرجعية من منتقي ملفات النظام. ولا يتطلب التطبيق Google Play Services.

## الميزات المدعومة

عبارة «متوافق مع OpenAI / Claude» تصف تنسيق الطلب، **ولا تضمن** توليد الصور أو عدد الصور المرجعية أو الخلفيات الشفافة أو الدقة أو استعادة المهام. الحالة الحالية:

| الواجهة أو الميزة | الحالة |
| --- | --- |
| OpenAI Images (`images/generations` و`images/edits`) | مُنفّذة، مع عدة صور مرجعية وإخراج URL / Base64 |
| OpenAI Chat Completions مع استدعاءات الأدوات | مُنفّذة في وضع Agent عبر `/chat/completions` |
| OpenAI Responses مع استدعاءات الأدوات | مُنفّذة في وضع Agent عبر `/responses` |
| Anthropic Messages مع استدعاءات الأدوات | مُنفّذة في وضع Agent |
| توليد الفيديو (إرسال إلى `videos` → استعلام `videos/{id}` → تنزيل من `url` أو `videos/{id}/content`) | مُنفّذ؛ الإرسال multipart افتراضيًا، ويقرأ `id`/`task_id` و`status`/`task_status` و`url`/`video_url`/`data[0]` (لم يُختبر بعد على بوابة حقيقية) |
| حلقة أدوات متعددة الخطوات في Agent (`generate_image` و`generate_video` و`create_deck` و`add_slide` و`add_table` و`ask_user` …) | مُنفّذة، حتى 32 خطوة في الدور؛ وتُعاد أخطاء الأدوات إلى النموذج كنتائج |
| تصدير العرض التقديمي (`.pptx` ومربعات النص / الصور / الجداول) | OOXML أصلي؛ قابل للتحرير في PowerPoint / WPS (لم يُختبر فتحه على جهاز حقيقي بعد) |
| WebFetch / `fetch_url` | المنفّذ ومخطط الأداة ما زالا في PR؛ ولم يُربطا بالحلقة |
| نتائج OpenAI Images عبر SSE | مُنفّذة؛ يمكن تفعيلها من خيارات توافق واجهة الصور |
| أداة Responses المدمجة `image_generation` | غير مُنفّذة؛ يستخدم Agent دالة التطبيق `generate_image` لاستدعاء واجهة Images المنفصلة |
| التحرير بالقناع، المهام المجمّعة، المزامنة السحابية، تشغيل النماذج محليًا | غير مُنفّذة؛ قد تُضاف لاحقًا |

قائمة النماذج لا تثبت قدرتها على توليد الصور، وفحص الاتصال ليس اختبارًا للتوليد. لا تبدأ اختبارات التوليد المدفوعة إلا عندما ترسل طلبًا صريحًا من المعرض. للتفاصيل، راجع [docs/capabilities.md](../../docs/capabilities.md).

## البناء

يتطلب Flutter مع Dart SDK ≥ 3.12.

تُنشأ مجلدات المنصات آليًا ولا تُحفظ في Git. ثم يضيف السكربت إليها الملفات الأصلية الخاصة بهذا المستودع:

```bash
python3 scripts/scaffold_platforms.py
flutter pub get
flutter run -d <device>
flutter build apk --release
```

ينشئ الأمر الأول مجلدات `android/` و`linux/` و`windows/` و`macos/`.

تتضمن CI ثلاثة مسارات: `check` للتحليل والاختبارات، و`build` لبناء APK تجريبي لـ Android، و`release` لتجهيز حزم المنصات الأربع عند دفع وسم يبدأ بـ `v`.

حزم الإصدار:

| المنصة | الحزم | أدوات التحزيم |
| --- | --- | --- |
| Android | APK | مُوقّع بمخزن مفاتيح الإصدار |
| Linux | `.deb` / `.rpm` / `.pkg.tar.zst` | `dpkg-deb` / `rpmbuild` / `bsdtar` |
| Windows | `.exe` / `.msi` لمعمارية x64 فقط | Inno Setup / WiX |
| macOS | `.dmg` / `.pkg` | `hdiutil` / `pkgbuild` |

حزم سطح المكتب **غير مُوقّعة**: يعرض Windows SmartScreen تحذير «ناشر غير معروف»، ويتطلب macOS فتح التطبيق بالنقر بزر الفأرة الأيمن. إزالة هذه التنبيهات تتطلب شهادة Authenticode وحساب Apple Developer ID، وهما غير متوفرين لديّ بعد. **لا توجد نسخة Windows بمعمارية 32 بت**، لأن Flutter لا يوفر هذا الهدف. لذا أعتذر حاليًا لمستخدمي Windows 7 وأنظمة win32 الأخرى.

## هيكل المشروع

| المسار | المحتوى |
| --- | --- |
| `lib/core/` | التخزين ونماذج البيانات وموائمات API وحالة التطبيق وكتابة `.pptx` |
| `lib/ui/` | واجهة المعرض وAgent وصفحة الفيديو ومساحة عمل العرض والإعدادات |
| `lib/l10n/` | النصوص وجداول الترجمة للغات الست |
| `platform/` | الملفات الأصلية الخاصة بالتطبيق التي تُضاف إلى ناتج `flutter create` |
| `scripts/` | إنشاء مجلدات المنصات وتوليد الترجمات |
| `docs/` | أدلة استخدام الواجهات والميزات |
| `test/` | تحليل البروتوكولات والتحقق من الإعدادات والترجمات |
